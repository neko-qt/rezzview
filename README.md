## rezzview
Pure C + GTK3 image viewer. Super minimalistic. Optimized for low-end computers and low RAM. That's literally the whole feature list.
Written simply because standard image viewers pull in half a ton of dependencies, take forever to launch, and eat RAM like there's no tomorrow. This project is built for anyone who needs to open an image on a lightweight system in a split second, zoom in with the scroll wheel, and close it without wasting CPU cycles on fancy animations and rounded corners.
It works fast, weighs next to nothing, and compiles with a single command.
## Dependencies
Gcc and gtk3 development headers.
## Build
```
make
```
